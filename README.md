# Cascade — Multi-channel Campaign Kit

**Project 03 / 04** of the Grok Bot showcase ladder for Adam Barnett / [ABCO Media](https://abcomedia.net).

> Desktop agents that actually ship.

One story across brief, landing, email, social, and slides — built to promote **xAI** and **Grok Bot** with Beacon as live proof.

## Open everything

From this folder:

```bash
# Option A — Python
python3 -m http.server 4174

# Option B — Node
npx --yes serve -l 4174
```

Then open:

| URL | File |
|-----|------|
| [http://localhost:4174/](http://localhost:4174/) | `index.html` — campaign landing |
| [http://localhost:4174/pitch-deck.html](http://localhost:4174/pitch-deck.html) | Fullscreen deck (← → keys) |

Or open any `.html` / `.md` directly in a browser or editor (`file://` works for the HTML).
